`scrippo` is a language for shell programs. You write `.scrippo` files with typed variables, indentation-scoped blocks, functions, and commands. The compiler emits bash, then runs it. Imports are resolved at compile time, so a finished script is one bash program with its libraries already inlined.

A script can be a single file you run, a package other files import, or a command tree with usage text and tab completion generated from the same declarations.

```scrippo
PI<const float>=3.14

circumference(diameter<float>)
  -> $PI * $diameter

-> "$(circumference 10)"
```

```bash
scrippo circumference.scrippo
```

## What you need

Running a compiled script needs Bash. Installing from Git needs Git and Bash. Building the compiler needs a Rust toolchain and `make`. The compiler version in this tree is 0.6.2.

These pages live in `docs/pages` and are a [Docusaurus](https://docusaurus.io) site published with GitHub Pages. Local preview needs Node.js 20 or newer: from `docs/pages`, run `npm install` and `npm start`. In the repository settings, set Pages to deploy from GitHub Actions. The workflow is `.github/workflows/pages.yml`.
